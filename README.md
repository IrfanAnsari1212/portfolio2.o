# Irfan Ansari — Portfolio

Static portfolio site with a React + TypeScript admin dashboard for editing it.

**Live:** <https://portfolio2-o-ten.vercel.app> · **Admin:** `/admin`

## How it works

Content lives in `content/*.json`, not in the markup. `npm run build` renders
`src/index.template.html` against that JSON to produce `index.html`, then compiles
the Tailwind stylesheet and the admin bundle.

The admin dashboard commits changes back to `content/*.json` through the GitHub API.
Vercel sees the commit and rebuilds, so the deployed page is always fully static —
no client-side data fetching, no database, and nothing lost to search engines.

```
content/*.json          the editable content
src/index.template.html markup with {{placeholders}}
src/input.css           Tailwind source
scripts/build-content.js template + JSON -> index.html
assets/                 styles.css, main.js, images, resume, certificates
admin-src/              admin dashboard source (see admin-src/README.md)
api/github-oauth.js     OAuth code -> token exchange
index.html  admin/      generated by the build
```

## Commands

```bash
npm install
npm run build       # index.html + styles.css + admin bundle
npm run dev         # watch the stylesheet while editing markup
```

`index.html` and `admin/` are build outputs. `index.html` is committed so the site
works even if the build is skipped; `admin/` is gitignored.

## Gotchas

- **New Tailwind class in the template?** Rerun `npm run build` or it will be missing
  from `assets/styles.css`.
- **Class only referenced from JavaScript** (toggled at runtime, or composed from a
  content field like an accent colour)? Add it to `safelist` in `tailwind.config.js` —
  the content scanner cannot see those, and they will be stripped.
- **Editing content?** Change `content/*.json`, not `index.html` — the build
  overwrites it.
